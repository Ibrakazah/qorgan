# Резервный план на случай отсутствия интернета

Qorgan не зависит от интернета на защите.

| Компонент | Нужен интернет? | Что происходит без него |
|---|---|---|
| Сервер и интерфейс | нет | работают на ноутбуке (`make demo`), внешних шрифтов, CDN и скриптов нет |
| База данных | нет | локальный SQLite в `.data/qorgan.db` |
| ИИ-разбор ответа | только для режима LLM | без ключа или сети включается офлайн-эвристика: бейдж «ИИ: офлайн (MOCK)», источник в кейсе — «офлайн-эвристика». Все демо-сценарии дают тот же результат |
| Видео-резерв | нет | `docs/media/qorgan_demo.mp4` — запись полного сценария, открывается любым плеером |
| Презентация | нет | `docs/submission/Qorgan_pitch.pptx` и PDF-копия на флешке |

## Чек-лист накануне
1. Ноутбук: `git pull`, `make install`, `make test` — всё зелёное.
2. Выключить Wi-Fi и пройти `docs/submission/DEMO_SCRIPT.md` целиком. Сценарий должен пройти без сети.
3. Скопировать на флешку: презентацию (`.pptx` + PDF), видео, ZIP репозитория.
4. Второй ноутбук или телефон с видео — на случай отказа основного.
5. Зарядка, переходник HDMI/USB-C.

## Если упал сам ноутбук
Показать видео с флешки на компьютере организаторов и комментировать по сценарию. Видео длится столько же, сколько живое демо.
