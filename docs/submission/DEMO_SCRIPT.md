# Сценарий демонстрации — 3:00

Демо идёт после слайда 6 презентации.

**Перед защитой (за 10 минут):**
1. `make demo` → открыть http://localhost:8000 в полноэкранном браузере, ширина ≥ 1400 px. Тогда все три роли видны на одном экране.
2. Нажать **«↺ Сбросить демо»** → подтвердить.
3. Проверить бейдж ИИ: «ИИ: LLM», если есть ключ и интернет, иначе «ИИ: офлайн-классификатор». Оба режима проходят сценарий одинаково.
4. Масштаб браузера 90–100%, звук уведомлений выключен, вкладка с видео-резервом открыта рядом (`docs/media/qorgan_demo.mp4`).

Ведущий говорит, второй участник кликает. Если человек один — кликать и говорить по тексту ниже.

**Если осталось время или спросят:** сценарий **7. «Ұлым апатқа түсті»** — Сауле отвечает на казахском, получатель обычный (не дроп), и перевод задерживает именно ИИ по смыслу ответа. Сценарий **9. Честная покупка машины** — крупный непривычный перевод получает только предупреждение: ложной тревоги нет. Сценарий **3** — звонок и сигнал «Телеком Антифрод», балл 100.

## Если что-то пошло не так
| Сбой | Действие (≤ 10 секунд) |
|---|---|
| Страница не грузится | Переключиться на вкладку с видео `docs/media/qorgan_demo.mp4` и комментировать по этому же сценарию |
| Нет интернета | Ничего не делать: приложение локальное, ИИ работает в офлайн-режиме (бейдж «офлайн-классификатор») |
| LLM отвечает медленно (> 5 с) | Сказать «модель думает», дождаться; при ошибке ответит офлайн-классификатор — сценарий тот же |
| Нажали не ту кнопку | «↺ Сбросить демо» → сценарий 2 с начала: 40 секунд |
| Проектор узкий (колонки ушли вниз) | Уменьшить масштаб браузера (Cmd/Ctrl −) до 75–80% |
