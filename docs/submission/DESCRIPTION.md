# Qorgan

**Кейс:** FINTECH CASE Банка ЦентрКредит, «Инновации в банкинге и кибербезопасности».
**Команда:** _[название, участники, роли]_

Qorgan («қорған» — защита) останавливает перевод, который человек делает под диктовку мошенника, и не трогает обычные переводы.

## Проблема
Самая частая схема мошенничества в Казахстане — звонок «из банка». Человека по телефону убеждают, что его деньги в опасности, и он сам переводит их на «безопасный счёт». Для банка это обычная операция: вход настоящий, подтверждение настоящее. В 2025 году было 28,9 тыс. дел об интернет-мошенничестве. По данным МВД о 2024 годе, в 98% случаев жертвы сами передали мошенникам свои данные.

Переводы во время звонка уже блокируют, но мошенники обходят это: звонят по видеосвязи на второй телефон. Чёрный список Антифрод-центра срабатывает после жалоб, когда деньги уже ушли.

## Что делает Qorgan
1. **Считает балл риска 0–100, и у каждого балла есть причина.** Учитывает звонок, удалённый доступ, сигнал оператора «Телеком Антифрод», сумму по сравнению с привычками клиента и признаки дропа у получателя: счёт открыт недавно, на него переводят десятки людей, деньги сразу уходят.
2. **Вмешивается соразмерно.** Перевод внуку проходит сразу. При среднем риске клиент видит предупреждение. При высоком — вопрос «зачем вы переводите?».
3. **Понимает ответ.** Языковая модель читает ответ на русском или казахском и узнаёт схему: «служба безопасности», «полиция», «родственник в беде», «инвестиции», «предоплата», «выигрыш». Так ловится обман даже без сигнала звонка.
4. **Не верит на слово.** Если получатель похож на дроп, перевод ждёт специалиста при любом ответе: клиента могли научить, что сказать. Модель может только добавить подозрение, отпустить деньги может только аналитик.
5. **Подключает людей.** Доверенное лицо (дочь, сын) получает уведомление с объяснением, но без доступа к счёту. Аналитик получает готовый кейс: причины балла, ответ клиента, вердикт модели, профиль получателя. После отклонения получатель попадает в стоп-лист банка.

## Что работает в MVP
- Веб-приложение: клиент, доверенное лицо и аналитик на одном экране; 9 сценариев (5 схем обмана, ответ на казахском, честные переводы без ложной тревоги); сброс демо одной кнопкой; работа без интернета.
- REST API с описанием OpenAPI, защита от двойной отправки (Idempotency-Key), SQLite.
- 104 автотеста, 74 из них проверяют логику Qorgan.
- Без ключа API работает офлайн-классификатор (символьные n-граммы + правила). На независимом тестовом наборе из 112 ответов (RU/KZ/транслит; синтетические ответы, их писал отдельный ИИ-агент без доступа к нашим правилам) он ловит 87% мошеннических ответов против 61% у одних правил; точность 0,83. Режим с языковой моделью не измерен: нужен ключ API.

## Что пока симуляция
Клиенты, счета и получатели синтетические. Сигналы телефона включаются переключателями в демо. Уведомления и передача в Антифрод-центр записываются в систему, но никуда не отправляются. Веса балла подобраны экспертно; откалибровать их можно только на данных банка.

## Отличие от того, что уже есть
Ближе всего к нам Revolut: при рискованном платеже он спрашивает цель и задаёт уточняющие вопросы. У Starling с июня 2026 есть ИИ-ассистент, который разбирает рассказ клиента, но на английском и по желанию клиента. Доверенный контакт есть у Monzo и Сбера. Мы не первые в отдельных элементах. Отличаемся тремя вещами:
1. **Ответ клиента не может снять тревогу.** Жертвам диктуют, что отвечать. Поэтому перевод на счёт-дроп ждёт специалиста при любом ответе.
2. **Закрываем казахстанский обход «второй телефон».** Срабатываем без звонка на устройстве: по получателю, сумме и ответу.
3. **Русский, казахский и их смесь, схемы под РК.** Плюс кнопка для доверенного лица «позвонить на основной номер», которая рвёт разговор с мошенником.

Плюс в продукте: быстрые кнопки ответа и вопрос «Вам сейчас кто-то говорит, что нажимать?» для пожилых клиентов; блок при удалённом доступе; дробление перевода на мелкие части ловится.

## Польза
- **Клиентам BCC:** по нашей оценке, 175–700 млн ₸ сохранённых денег в год. Это цель пилота с явными допущениями, расчёт в `ECONOMICS.md`.
- **Банку:** меньше обязательных возмещений по переводам на «чёрных» получателей и меньше ручной работы аналитиков.
- **Стоимость ИИ:** около 43 000 ₸ в месяц, потому что модель спрашивают только про подозрительные переводы.
