# Qorgan — описание проекта для заявки

**Кейс:** FINTECH CASE Банка ЦентрКредит «Инновации в банкинге и кибербезопасности».
**Направления кейса:** антифрод и выявление мошеннических операций; защита клиентов; повышение безопасности финансовых операций.

## Одной фразой
Qorgan («Қорған» — «защита») останавливает перевод, который клиент делает под диктовку мошенника. Честные переводы при этом проходят без лишних вопросов.

## Проблема
Интернет-мошенничество в Казахстане достигло рекорда: 28,9 тыс. дел в 2025 году, почти четверть всей преступности. Самая частая схема — звонки «от имени банка». По данным МВД, в 98% случаев жертвы сами передают деньги и данные. Классический антифрод такие переводы не замечает: вход и подтверждение настоящие, клиент действует сам.

Требование блокировать переводы во время звонка (по сообщениям СМИ — уже действует) мошенники обходят: жертву держат на видеосвязи со **второго телефона**. Чёрный список Антифрод-центра реактивен: дроп попадает туда только после жалоб.

## Решение
В момент перевода Qorgan:
1. **Считает объяснимый балл риска 0–100.** Учитывает сигналы сессии (звонок, удалённый доступ, новое устройство, сигнал «Телеком Антифрод»), сумму относительно привычек клиента и признаки дропа у получателя (молодой счёт, много отправителей за сутки, мгновенный вывод). Каждый балл подписан причиной.
2. **Выбирает уровень вмешательства:** пропустить без вопросов → предупредить → проверочный диалог → задержать.
3. **Проверочный диалог с ИИ.** Клиент своими словами (на русском или казахском) объясняет, зачем переводит. Языковая модель узнаёт сценарий обмана: «служба безопасности», «полиция», «родственник в беде», «инвестиции», «предоплата», «выигрыш», давление без сценария. Это ловит обход через второй телефон, когда сигнала звонка нет.
4. **Задерживает перевод и подключает людей.** Доверенное лицо (дочь, сын) получает уведомление с причиной и отвечает «это мошенники» или «всё нормально». Аналитик банка получает готовый кейс: балл с расшифровкой, ответ клиента, вердикт ИИ, профиль получателя, хронологию. Решения: отклонить и передать получателя в стоп-лист / АФЦ, выпустить, отметить ложное срабатывание.

**Главный принцип:** ИИ может только ужесточить решение. Выпустить задержанный перевод может только человек.

## Что работает в MVP
- Веб-приложение с тремя ролями на одном экране: клиент, доверенное лицо, аналитик.
- 5 демо-сценариев, сброс демо одной кнопкой, работа без интернета.
- REST API с OpenAPI-описанием (`/docs`), SQLite, 71 автотест.
- ИИ-задача `scam_script`: LLM со строгой JSON-схемой при наличии ключа. Без ключа и при сбое модели работает офлайн-эвристика.
- Оценка качества на 63 размеченных синтетических ответах: эвристика даёт accuracy 0,841, macro-F1 0,846, ложные срабатывания на честных ответах — 15%. Ошибки приходятся на перефразировки — ровно там, где нужна LLM.

## Что симулировано (честно)
Клиенты, счета и получатели — синтетические. Сигналы телефона задаются в демо-панели. Уведомления и передача в Антифрод-центр записываются в систему, но никуда не отправляются. Веса модели риска экспертные и не откалиброваны на данных банка.

## Чем отличается от существующего
Отдельные элементы на рынке есть: блокировка при звонке, «Доверенный контакт» Kaspi, «Вторая рука», инициатива НБРК об ИИ-звонке о цели перевода, чёрные списки АФЦ. Qorgan собирает их в **один объяснимый поток**:
- градуированное трение вместо «блок / не блок»;
- оценка «серых» дропов до попадания в базу;
- понимание ответа клиента в тексте — дешевле и тише голосового бота;
- объяснение для доверенного лица;
- кейс, готовый для аналитика и АФЦ;
- приём сигнала «Телеком Антифрод».

## Польза
- **Клиенту:** деньги остаются у него, а обычные переводы не тормозятся.
- **Банку:** меньше обязательных возмещений по переводам на «чёрных» получателей, меньше ручной работы аналитиков, встраиваемый модуль с API.
- **Оценка:** при допущениях из `ECONOMICS.md` — 175–700 млн ₸ предотвращённого ущерба в год для клиентов BCC. Это цель пилота, а не измерение. ИИ стоит около 43 000 ₸ в месяц.

## Следующий шаг
Офлайн-прогон модели риска на обезличенной истории инцидентов BCC → теневой режим → пилот на 5–10% клиентов с A/B-контролем (`INTEGRATION.md`).
