# Прогресс и решения (для продолжения после перезапуска)

Обновлено: 2026-11-15.

## Ключевые решения
- **Кейс открытый** (подтверждено цитатами, `docs/CASE.md`). Выбран концепт A — защита от социальной инженерии в момент перевода (`docs/IDEAS.md`, скоринг 58/65).
- **Позиционирование после исследования** (`docs/research/RESEARCH.md`): блокировка переводов во время звонка в РК уже требуется (по данным СМИ), доверенный контакт есть у Kaspi. Поэтому главный демо-сценарий — обход через **второй телефон** (сигнала звонка нет), а ценность — связка «балл → трение → ИИ-разбор ответа → доверенное лицо → кейс аналитику».
- **Стек:** шаблон комплекта `ai-service` (FastAPI, слой LLM с mock-режимом), SQLite, ванильный HTML/JS без CDN (демо работает офлайн).
- **Правила вместо ML** для балла риска: размеченных данных банка нет. ИИ используется только для понимания свободного текста.
- **Инвариант:** ИИ только ужесточает решение, выпускает перевод только аналитик.
- **Рабочий дедлайн — 21.11.2026** (пост вуза), пока организаторы не подтвердят 26.11 из правил.

## Команды
| Что | Команда |
|---|---|
| Установка | `make install` |
| Демо | `make demo` → http://localhost:8000 |
| Тесты / линтер / типы | `make test`, `make lint`, `make typecheck` |
| Оценка ИИ | `make eval TASK=scam_script DATASET=evals/datasets/scam_script.jsonl` |
| Видео и скриншоты | `make demo` в одном терминале, `make record` — в другом |
| Презентация | `make deck` |
